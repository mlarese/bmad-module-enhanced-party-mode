# Jurisdiction Scoping

## What Success Looks Like
Prima della sostanza, esiste una **cornice** condivisa: giurisdizione primaria, eventuali confronti, settore/prodotto rilevante, e perché quella cornice conta. Il consumatore è il parere successivo (GC/AI/CJ/RV): senza scoping, ogni risposta "mondiale" è rumore. Se l'owner arriva già con la cornice, confermala in una riga e vai avanti — non rifare l'intake.

## Non-inferables
- Default: chiedi UE/Italia vs altro solo se manca; usa BOND.md se già noto.
- Se servono più giurisdizioni, proponi un confronto mirato (CJ) invece di una rassegna enciclopedica.
- Scrivi preferenze stabili in BOND.md appena emergono.
