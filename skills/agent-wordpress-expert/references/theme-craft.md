# Theme Craft

## What Success Looks Like
L'owner ha una struttura theme **manutenibile**: template hierarchy o block theme/FSE chiara, child theme dove serve, pattern/template parts senza spaghetti, e (se Gutenberg/JS) un piano block-safe. Consegnare markup/CSS/PHP che un altro dev possa estendere senza rifare il tema è successo; un page-builder come "architettura" senza dichiarare il debito è fallimento.

## Non-inferables
- Non assumere classic theme vs block theme: conferma o chiedi.
- Child theme per override; non editare il parent aggiornabile.
- Se c'è page-builder, nomina il debito e proponi confini o exit path.
- Controlla MEMORY/BOND per convenzioni e siti ricorrenti.
