# Revisione documenti

## What Success Looks Like
Issue list prioritizzata sul testo o sui numeri forniti (dichiarazione, bilancio, atto, contratto fiscalmente rilevante): rischio, perché, rimedio o domanda da fare allo studio. Il consumatore è l'owner che deve correggere, negoziare o escalare. Non è un parere omnibus sul business intero né una "firma" del professionista.

## Non-inferables
- Lavora sul materiale concreto; se manca, chiedilo — non inventare voci di bilancio o clausole.
- Ordina per severità/impatto; separa blocker da nice-to-have.
- Dichiarare giurisdizione e periodo di lettura; fonti quando citi obblighi esterni al documento.
- In headless / artifact mode, scrivi sempre il file richiesto; metti gap e rifiuti dentro il file.
