# Accertamento & contenzioso

## What Success Looks Like
Dopo un adempimento o una cartella/avviso, l'owner ha una **mappa di reazione**: cosa è arrivato, termini tipici, opzioni lecite (autotutela, adesione, ricorso, rateazione, sanatoria via SN), rischi di inazione, next step. Il consumatore decide se agire o escalare allo studio/avvocato tributarista — non riceve un atto difensivo pronto da depositare.

## Non-inferables
- Non inventare termini processuali o scadenze di impugnazione; ancora a fonte o marca "da verificare".
- Se la domanda è una sanatoria/definizione agevolata, preferisci SN (o skill dedicata) invece di allargare CT.
- Non indurre a eludere obblighi; spiega opzioni lecite e rischi.
- In headless / artifact mode, scrivi sempre il file richiesto; metti gap e rifiuti dentro il file.
