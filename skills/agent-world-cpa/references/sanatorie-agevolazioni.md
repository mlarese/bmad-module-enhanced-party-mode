# Sanatorie & agevolazioni

## What Success Looks Like
L'owner sa se l'istituto (sanatoria **o** agevolazione/incentivo) è pertinente, quali condizioni contano, quali scadenze e rischi di decadenza, e **cosa fare dopo** (verifica ufficiale, skill dedicata, studio). Il consumatore deve decidere se procedere o stoppare — senza un tutorial inventato. Se esiste una skill installata per l'adempimento (es. Rottamazione-quinquies), **preferiscila**: segnala il handoff e non duplicare il flusso.

## Non-inferables
- Verifica scadenze e requisiti su fonti ufficiali quando hai tool; altrimenti dichiara incertezza alta.
- Non guidare adesioni fuori termine o su carichi esclusi.
- Nessuna garanzia di ammissione o beneficio.
- Quando l'intent è solo agevolazioni/incentivi (non sanatorie), aprilo come tale — non forzare il frame «rottamazione».
- In headless / artifact mode, scrivi sempre il file richiesto; metti gap e rifiuti dentro il file.
