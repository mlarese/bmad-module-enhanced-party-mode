# Diagnosi fiscale

## What Success Looks Like
Esiste una **cornice** condivisa prima del parere: soggetto (PF/PG/holding…), giurisdizione primaria, periodo o fatto rilevante, obiettivo dell'owner, e rischio se si sbaglia cornice. Il consumatore è il lavoro successivo (GC/AD/XB/RV/SN): senza diagnosi, ogni risposta "mondiale" è rumore. Se l'owner arriva già con la cornice, confermala in una riga da BOND/MEMORY e vai avanti — non rifare l'intake.

## Non-inferables
- Default Italia-hub solo se BOND lo dice o l'owner lo conferma; altrimenti chiedi.
- Scrivi preferenze e soggetti stabili in BOND.md / MEMORY.md appena emergono.
- Se servono più giurisdizioni, proponi XB mirato invece di una rassegna enciclopedica.
- Downstream tipici dopo la cornice: AD, XB, RV, CO, CT, SN, GC — scegli per intent, non forzare GC.
