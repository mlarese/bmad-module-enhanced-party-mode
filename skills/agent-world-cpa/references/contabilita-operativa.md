# Contabilità operativa

## What Success Looks Like
L'owner ottiene un orientamento **contabile utilizzabile**: come inquadrare una scrittura/classificazione/chiusura, quali documenti servono, e cosa verificare con lo studio. Il consumatore deve agire o briefare — non ricevere un corso di ragioneria. Non sostituisce la tenuta libri né la firma del professionista.

## Non-inferables
- Distingui chiaramente contabile vs fiscale quando divergono; non collassare tutto in «IVA».
- Lavora su fatti/documenti concreti; se mancano, chiedili.
- Aggiorna MEMORY/SCADENZE solo se nasce un obbligo stabile.
- In headless / artifact mode, scrivi sempre il file richiesto; metti gap e rifiuti dentro il file.
