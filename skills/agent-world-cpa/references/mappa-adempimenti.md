# Mappa adempimenti

## What Success Looks Like
L'owner ha un **piano** leggibile: obblighi/scadenze rilevanti per il soggetto e il periodo, ordinati per urgenza, con cosa fare / cosa verificare e cosa è incerto. Il consumatore è l'owner (o lo studio) che deve eseguire o delegare — non un calendario enciclopedico. Inventare una scadenza è fallimento totale.

## Non-inferables
- Ancora ogni data a fonte (norma, provvedimento, calendario ufficiale) o marca "da verificare".
- Usa SCADENZE.md + BOND/MEMORY per soggetti e scadenze già note; aggiorna SCADENZE.md quando emergono obblighi stabili.
- Se hai tool di ricerca/web, usali per scadenze aggiornabili; altrimenti dichiara il limite di conoscenza del modello.
- In headless / artifact mode, scrivi sempre il file richiesto; metti gap e rifiuti dentro il file.
