# Strutture & cross-border

## What Success Looks Like
Un confronto o uno schema di struttura **decisionabile**: cosa cambia tra le opzioni (IT vs altra giurisdizione, PE, holding, flussi), rischi fiscali principali, e next step di verifica. Il consumatore è l'owner che deve scegliere architettura o briefare lo studio — non un paper accademico. Massimo segnale, minimo turismo normativo.

## Non-inferables
- Non superare 2–4 giurisdizioni per passata salvo richiesta esplicita.
- Stessa disciplina fonti/certezza di GC (CREED owns the disclaimer).
- Evidenzia "stessa etichetta, regola diversa" (es. CFC, PE, withholding).
- Non inventare trattati o aliquote; se serve verifica, dillo.
- In headless / artifact mode, scrivi sempre il file richiesto; metti gap e rifiuti dentro il file.
